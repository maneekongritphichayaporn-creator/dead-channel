# DEAD CHANNEL

เกมสืบสวนแนว analog horror ที่ให้ผู้เล่นรับบททีมสืบสวนเหตุผิดปกติจากสถานีออกอากาศร้าง ตรวจหลักฐานจากเทป VHS ภาพ CCTV และบันทึกข้อความ ก่อนเชื่อมโยงสัญญาณที่ไม่ควรมีอยู่กับเหตุการณ์ในสถานี

## เล่นเกม

[เปิด DEAD CHANNEL บนเว็บ](https://dead-channel-nu.vercel.app/)

## เนื้อหา

- ห้องสืบสวนและกระดานเชื่อมโยงหลักฐาน
- เครื่องเล่น VHS และไฟล์หลักฐาน VHS-001, CCTV-004 และ TXT-017
- ปริศนาถอดสัญญาณ ตรวจเวลา และวิเคราะห์หลักฐาน
- การตัดสินใจและผลลัพธ์ที่เปลี่ยนตามเส้นทางสืบสวน
- เนื้อเรื่องหลัก Case 001–024 พร้อมบทสรุปหลายแบบ
- บันทึกความคืบหน้าไว้ในเบราว์เซอร์ และส่งออกรายงานคดีได้

## ความต้องการ

- Node.js รุ่นที่ Vite 8 รองรับ
- npm
- เบราว์เซอร์รุ่นใหม่ เช่น Chrome หรือ Edge

โปรเจกต์นี้ใช้ React และ Vite สำหรับพัฒนาและสร้างไฟล์พร้อมเผยแพร่

## ติดตั้งและเปิดเกม

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal (โดยทั่วไปคือ `http://localhost:5173`) หากต้องการหยุดเซิร์ฟเวอร์ ให้กด `Ctrl+C` ใน Terminal

บน Windows หาก PowerShell แจ้งว่าบล็อกสคริปต์ `npm`, ให้ใช้ Command Prompt หรือเรียกคำสั่งผ่าน `npm.cmd` เช่น `npm.cmd run dev`

## ตรวจสอบและสร้างไฟล์เผยแพร่

```bash
npm run lint
npm run build
```

ไฟล์สำหรับเผยแพร่จะอยู่ในโฟลเดอร์ `dist/` ซึ่งไม่ควร commit เข้า Git เพราะสร้างใหม่ได้ด้วยคำสั่ง build

ทดลองเปิดไฟล์ที่ build แล้วในเครื่อง:

```bash
npm run preview
```

## ความคืบหน้าและข้อมูลบันทึก

เกมบันทึกความคืบหน้าไว้ใน Local Storage ของเบราว์เซอร์และโปรไฟล์ที่ใช้เล่น หากเปิดเกมในเบราว์เซอร์หรือโปรไฟล์อื่น ความคืบหน้าจะไม่ตามไปด้วย

เริ่มเกมใหม่จากหน้า Title Screen โดยเลือก `START NEW CASE` แล้วกดยืนยัน `CLEAR SAVE AND RESTART` การล้างข้อมูลนี้จะลบความคืบหน้าของเกมในเบราว์เซอร์นั้น

## โครงสร้างโปรเจกต์

- `src/App.jsx` — ฉาก เกมเพลย์ สถานะคดี และการบันทึกความคืบหน้า
- `src/App.css` — รูปแบบหน้าจอและองค์ประกอบเกม
- `src/main.jsx` — จุดเริ่มต้นของแอป React
- `public/` — ไฟล์สาธารณะที่ Vite ให้บริการ

## สคริปต์ที่ใช้ได้

- `npm run dev` — เปิดเซิร์ฟเวอร์พัฒนาพร้อม Hot Module Replacement
- `npm run lint` — ตรวจโค้ดด้วย ESLint
- `npm run build` — สร้างไฟล์ production ลง `dist/`
- `npm run preview` — แสดงตัวอย่างไฟล์ production ในเครื่อง
